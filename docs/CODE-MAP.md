# Code map — where things live (verified 2026-10-21 against upstream main @ 169b42f)

One entry per subsystem: path(s), the functions to start reading at, and what matters for our work. Zero Hour code is under
`GeneralsMD/Code/`; anything shared between Generals and Zero Hour was hoisted by upstream into `Core/` (same layout underneath).
`Core/Libraries/Source/WWVegas/` is Westwood's W3D/WW3D2 renderer and libraries. Ignore `Generals/` (the older game) entirely.
"TSH" = TheSuperHackers change, marked in source as `// TheSuperHackers @tag author date`.

## Reading order for each plan phase

- **Phase 4 netcode:** Network frame delay → CRC check → Input→commands → Main loop (network branch) → Save/snapshot (for resync).
- **Phase 5 render:** Main loop & frame pacing → Drawable boundary → W3D display → Device layer.
- **Phase 7 movement:** AI states → Locomotor → Physics → Pathfinder → Partition manager. Everything here is in the CRC.
